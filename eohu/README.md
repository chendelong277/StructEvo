# EoH-U

This directory contains the EoH-U source code used in the public repository.

## Example Usage

```bash
python main.py --problem tsp
python main.py --problem cvrp
```

## Configuration

Edit `config/tsp_config.py` and `config/cvrp_config.py` before execution. The default model is `deepseek-v3`, and API fields are placeholders.
